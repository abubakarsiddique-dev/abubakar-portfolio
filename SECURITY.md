## Reporting a Vulnerability

Security issues and vulnerabilities are taken seriously. If you discover a potential security flaw in this portfolio application or its deployment configurations:

1. **Do not open a public GitHub issue** with sensitive vulnerability details.
2. Please send a detailed report directly via email to:
   - **Contact**: `abubakar1siddique2@gmail.com`
3. Include the following details to help triage and reproduce the issue:
   - Type of issue (e.g. Cross-Site Scripting, Header misconfiguration, Dependency CVE)
   - Step-by-step instructions or proof-of-concept to reproduce the behavior
   - Affected URLs, endpoints, or browser environments
   - Potential impact and recommended mitigation if available

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of report receipt.
- **Triage & Status Update**: Within 5 business days after validation.
- **Fix & Deployment**: Security patches are prioritized and released via GitHub Actions CI pipeline.
